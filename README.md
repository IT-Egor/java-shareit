# java-shareit
**Веб-приложение для шеринга вещей.**  
Приложение позволяет пользователям брать в аренду и предлагать в аренду различные предметы.
Template repository for Shareit project.

## 🎯 Цель проекта
- Практика разработки на Spring Boot с многомодульной архитектурой проекта
- Освоение работы с JPA/Hibernate для доступа к данным
- Освоение работы с Docker
- Освоение работы с библиотекой для маппинга данных (MapStruct)
- Практика углубленной работы с исключениями (собственные исключения, централизованная обработка исключений)
- Практика написания модульных (с использованием `Mockito`), интеграционных (`@SpringBootTest`) и web (`@WebMvcTest`) тестов
- Практика работы с системой проверки качества кода (Checkstyle, JaCoCo)
- Изучение основ работы со шлюзами (gateway)

## 📋 Функциональность
- Полный цикл CRUD для пользователей
- Полный цикл CRUD для вещей
- Создание и поиск комментариев к вещам
- Поиск доступных для аренды вещей по названию
- Создание и поиск запросов на шеринг отсутствующих вещей
- Создание, подтверждение и поиск бронирований
- Простой шлюз

## ⚙️ Технологический стек
- **Язык:** Java 21
- **Фреймворк:** Spring Boot
- **База данных:** PostgreSQL 16, H2
- **Доступ к данным:** Spring Data JPA, Hibernate
- **Сборка:** Maven

- **Тестирование:** JUnit 5, Mockito

## 🏗️ Архитектура и ключевые компоненты

### Модель данных
Система работает со следующими сущностями:

| Сущность                   | Описание                                                                                                                |
|----------------------------|-------------------------------------------------------------------------------------------------------------------------|
| **Пользователь (User)**    | Зарегистрированный участник системы, может владеть вещами, создавать бронирования и запросы.                            |
| **Запрос (Request)**       | Запрос пользователя на вещь, которой ещё нет в системе. Другие пользователи могут видеть запрос и добавить нужную вещь. |
| **Вещь (Item)**            | Предмет для совместного использования. Принадлежит пользователю, может быть доступна или не доступна для бронирования.  |
| **Бронирование (Booking)** | Заявка на аренду вещи на определённые даты. Имеет статус (ожидание, подтверждено, отклонено, отменено).                 |
| **Комментарий (Comment)**  | Отзыв пользователя о вещи, который можно оставить после завершения её аренды.                                           |


### Основные сервисы

#### 1. **UserService**
- Полный цикл CRUD
- Проверка уникальности email при регистрации и обновлении данных

#### 2. **ItemService**
- Полный цикл CRUD
- Привязка вещей к запросам (если вещь добавлена в ответ на запрос)
- Получение вещей с информацией о ближайших бронированиях и комментариями
- Добавление комментариев к вещам с проверкой прав (только после завершенного бронирования)
- Поиск доступных вещей по текстовому запросу

#### 3. **BookingService**
- Создание запросов на бронирование вещей
- Подтверждение или отклонение бронирований владельцами вещей
- Получение информации о конкретном бронировании (доступно только арендатору или владельцу)
- Получение списков бронирований для арендаторов и владельцев с фильтрацией по статусам
- Валидация дат бронирования и доступности вещей

#### 4. **RequestService**
- Создание запросов на вещи, которых нет в системе
- Получение собственных запросов пользователя с предложенными вещами
- Просмотр всех запросов других пользователей
- Получение конкретного запроса по идентификатору
